If something is not working

  • Page won't load: check docker ps shows the container as Up and the port is mapped as host:container, for example 8080:80.
  • Connection reset: the app must listen on 0.0.0.0, not 127.0.0.1, inside the container.
  • 403 or 404 from nginx: files must be in /usr/share/nginx/html and the file must be named index.html.
  • Old page after an edit: rebuild the image, or mount the folder as a volume. Then hard refresh with Ctrl+Shift+R.
  • Container exits at once: read docker logs docker-test for the error.
  • Spring Boot or API container: use the tester above on /actuator/health or your own endpoint.
